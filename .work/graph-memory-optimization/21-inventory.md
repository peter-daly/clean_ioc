## Temporary source seam and follow-on handoff

`AnalysisResult._composition_blueprint` explicitly owns successful analysis source. `ScopeBuilder._from_blueprint(parent, blueprint)` is a **private temporary test seam**, with `_source_blueprint` used only by builder declaration readers. No execution runtime owns or points back to that source. It intentionally does not claim public immutable Composition capture or parent-lineage matching.

Current seam callers are `tests/test_analysis_pipeline.py` (inherited rules), `tests/test_policies.py` (two policy inheritance cases), `tests/test_factory_return_types.py` (overlay factory check), `tests/test_build_matrix.py` (overlay result closure), and `tests/test_execution_plan.py` (borrowed anchors/cleanup, closed parent and failed scope admission). Ordinary build source is released; task23 must capture explicitly requested source at the snapshot/preparation boundary before that release. No Composition close/aclose/context manager is introduced.
