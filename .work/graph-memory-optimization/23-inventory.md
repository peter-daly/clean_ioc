There is still a private historical `_observe_plan` harness adapter, which delegates directly to the compact observer; it is not used by public builds. Task24 removes that harness with remaining old runtime inspection properties and migrates the full test/docs/consumer surface. Composition's builder-private restored blueprint is an active builder owner, not the removed runtime/result blueprint convenience seam.

No object population, peak allocation, memory or timing comparison was performed. Optional profiling and retained handles have real ownership costs. Task25 measures those costs after integration; constructor sentinels and weakrefs here prove only their stated allocation/lifetime properties.
